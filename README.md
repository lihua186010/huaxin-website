# 北京中航华信机电设备安装有限公司 官方网站

蓝色 × 灰色科技风，自适应电脑 / 平板 / 手机，无任何第三方依赖，纯静态部署。

## 使用方式

直接双击打开 `index.html` 即可本地预览；正式上线时把整个 `site` 文件夹上传到服务器（或任意静态托管，如阿里云 OSS / 腾讯云 COS / Nginx / GitHub Pages）即可。

## 目录结构

```
site/
├── index.html          首页（首屏轮播 / 数据统计 / 核心业务 / 智慧平台 / 领域 / 案例 / 资质 / 新闻）
├── about.html          关于我们（公司简介 / 发展历程 / 组织架构 / 核心团队 / 企业文化 / 资质荣誉）
├── business.html       业务与产品（四大成熟业务 / 智慧消防平台 / 消控室运营 / 研发储备 / 服务流程）
├── cases.html          项目案例（按 机场/地铁/医院/公建/企业/智慧 分类筛选）
├── news.html           新闻动态
├── contact.html        联系我们（联系方式 / 在线留言表单）
└── assets/
    ├── css/style.css   全站样式（设计系统：颜色变量 / 组件 / 响应式断点）
    ├── js/main.js      全站交互（轮播 / 粒子 / 滚动动画 / 移动导航 / 筛选 / 表单）
    └── img/            已压缩优化的图片素材（含 Logo、证书、平台截图、案例图）
```

## 内容维护

- **新闻动态**：编辑 `news.html` 与 `index.html` 的"新闻动态"区块即可。
- **项目案例**：在 `cases.html` 中复制卡片结构，修改 `data-cat`（airport / metro / medical / public / corp / smart）即可归入对应分类。
- **联系方式**：顶部条、页脚、联系我们页三处的电话 / 地址需同步修改。
- **Logo**：替换 `assets/img/logo.svg`（六边形 + 火焰 + 双翼 + 信号点）与 `favicon.svg`。
- **备案号**：上线前在页脚 `footer-bar` 补充 ICP 备案号。
